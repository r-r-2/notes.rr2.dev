Setting up notes.rr2.dev

Sep 12, 2026 — Worklog • Home.

TL;DR: Rahul forked Arnav Gupta's sites.arnavg.in — a dumpyard for LLM-agent-generated static pages — and adapted it into this site: a personal, GitHub Pages-hosted collection of the notes, reports, and visualizations that come out of his sessions with LLM agents.

The inspiration

LLM sessions constantly produce small artifacts worth keeping — a written-up explanation, a research summary, a one-off visualization — and they usually scroll out of a chat window and are lost. Arnav's sites.arnavg.in solved that elegantly: park each artifact at a personal domain as a self-contained static HTML page, kept purely for reference. Rahul liked the idea and the no-framework, no-build restraint of it, so he forked it. Full credit to Arnav for the original project and its clean design.

What it is

Every page under this domain is a self-contained HTML file (inline CSS/JS, no build step, no frameworks) generated by an LLM agent. Three sections:

  • /research/ — reports
  • /learning/ — guides
  • /worklog/ — this log

How it's built

  1. Hosting — static files served from the repo root via GitHub Pages, custom domain wired up through Cloudflare DNS and a CNAME.
  2. Publishing — an agent adds a page by dropping a research/<slug>/, learning/<slug>/, or worklog/<slug>/ folder, via the gh CLI, the GitHub MCP server, or the REST API. A publish-site-artifact skill packages those instructions so any agent can do it.
  3. Listings — a GitHub Action regenerates each section's index and the homepage item counts automatically, so no index is ever hand-maintained. Link text comes from each page's <title>; worklog entries carry a <meta name="date"> so their date shows in the log.

Why

A durable, linkable home for the good stuff that would otherwise disappear when the chat window closes.
