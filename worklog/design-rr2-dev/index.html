I don't write UI code myself anymore; agents do. Today I put the look my sites share in one place an agent can read.

See it at design.rr2.dev →

Code: github.com/r-r-2/design

Why I made it

Each new site borrows from the ones before it. notes took its look from rr2.dev, and resume took its header from notes. I want that to stay easy, so the parts they share now live in one place, and the next site can start from there.

What's in it

  • Two colours from my profile photo. Raspberry from the shirt, slate from the sky, on grey paper with dark ink. Fraunces for headings, Instrument Sans for reading.
  • A DESIGN.md for agents. It follows Google's new DESIGN.md format: the tokens at the top, then the rules and the exact markup for 24 components. An agent reads it and copies from it instead of guessing.
  • Versioned CSS. Sites link to /personal/v1/, so a later change can't break them.
  • A checker. A small script the agent runs after building. It flags hard-coded colours, made-up class names, and more than one main button on a page. The design site passes its own check.
  • Review pages for me. Live previews in light and dark, with the HTML next to each one.
