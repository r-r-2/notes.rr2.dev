Why I made it

At meetups, people often ask what I've worked on. Now I can just show them.

How I made it

I built it with Claude (Opus 5.5). The idea and the design were mine: I'd describe what each slide should show, Claude would suggest a few ways to do it, I'd pick or push back, and Claude built it.

  • The site: plain HTML, CSS and JavaScript with no framework, hosted on Cloudflare and deployed straight from GitHub.
  • The animations: each slide has one small animation of the work happening, drawn in code. The world map uses D3.
  • The launch video: made in code with Remotion. Even the marimba track was generated in code, timed to land on the scene changes.

What I'd like to add in future

  • A terminal version over SSH, for people who'd rather type than scroll.
