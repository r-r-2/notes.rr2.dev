Karpathy's aircraft manual trick for LLMs

This version uses the STE rules: short sentences, active voice, simple words, one meaning for each word.

"We'll be spending a lot more time trying to understand the outputs of language models. A few thoughts, tips & tricks:

Writing. Something I've had success with: Ask your LLM to explain something in ASD-STE100, it's a controlled language specification originally developed for aerospace maintenance documentation. LLMs well-versed in this language and it comes with heavy constraints on clean writing style that I often find a lot more readable. Sometimes I've tried to soften it a bit e.g. ask for "80% of the way to ASD-STE100" because the spec is quite stringent. But even better: …"

So where do we get strict rules?

Where can we find strict rules?

From airplanesThe rules come from aircraft maintenance

Picture a mechanic at 3 a.m. English is their second language.

A mechanic repairs an aircraft at night. English is not the first language of the mechanic.

If they misread the manual, a plane can break.

If the mechanic does not understand the manual, damage to the aircraft can occur.

So in the 1980s the aircraft industry wrote ASD-STE100, also called Simplified Technical English. It is a rulebook for English that nobody can misread.

Thus, the aircraft industry wrote ASD-STE100 in the 1980s. The other name is Simplified Technical English (STE). STE is a set of rules for English. With these rules, each reader understands a text in only one way.

Before"Prior to initiating the procedure, ensure that power has been disconnected."
STE"Disconnect the power. Then start the procedure."

Why it works on LLMsWhy the rules help an LLM

The model already knows the rulebook. One name loads all the rules.

The model knows the STE rules. One name gives all the rules to the model.

The rules are hard limits. There is no room for filler.

The rules have strict limits. The model cannot add words that have no function.

They ban the exact bad habits. Long sentences, fancy words and passive voice are all out.

The rules stop the bad habits. Long sentences, complex words and the passive voice are not permitted.

Why "80%"?Why use 80%?

The full rules are for the repair of machines. When you explain ideas, the text can sound like a robot wrote it.
