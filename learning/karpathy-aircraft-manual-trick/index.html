The problem

LLMs often write like this:

Typical LLM"Great question! It's worth noting that this can essentially be leveraged to facilitate…"

Too many words. Long sentences. Fancy verbs. Lots of "maybe".

You read it twice and still miss the point.

Why does it happen?

The model learned from essays, ads and polite emails. So it tries to sound smart.

Root cause: it has no strict rules for clear writing. "Be concise" is too vague.

So where do we get strict rules?

From airplanes

Picture a mechanic at 3 a.m. English is their second language.

If they misread the manual, a plane can break.

So in the 1980s the aircraft industry wrote ASD-STE100, also called Simplified Technical English. It is a rulebook for English that nobody can misread.

Before"Prior to initiating the procedure, ensure that power has been disconnected."
STE"Disconnect the power. Then start the procedure."

Why it works on LLMs

The model already knows the rulebook. One name loads all the rules.

The rules are hard limits. There is no room for filler.

They ban the exact bad habits. Long sentences, fancy words and passive voice are all out.

Why "80%"?

The full spec was made for fixing machines. For ideas, it can sound like a robot.

80% keeps the short, plain style but allows normal words. Try it:

Same topic each time: what a cache is.

In short

  1. LLMs write wordy text by default.
  2. Vague advice does not fix it.
  3. STE is a strict rulebook the model already knows.
  4. 80% keeps it clear without sounding robotic.
